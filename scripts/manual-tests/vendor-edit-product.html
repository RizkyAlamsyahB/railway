Target Product

Status: -

Edit Product

Ini adalah PUT (full-replace). Semua field wajib diisi ulang meskipun tidak berubah.

Variants (Non-Default)

Default variant diperbarui dari field price / stock / weight_gram di atas.
● EXISTING = varian lama (punya ID) → diperbarui. ● NEW = varian baru (tanpa ID) → dibuat baru.
Varian lama yang tidak ada di tabel ini akan dinonaktifkan.

type id (existing) variant_name * price * stock weight_gram is_active action

Existing Images (keep_image_ids)

Centang gambar yang ingin dipertahankan. Gambar yang tidak dicentang akan dihapus. Jika belum load product detail, tambah ID manual di bawah.

keep image_id object_key / url primary

New Images (new_images)

Total gambar setelah update (dipertahankan + baru) maksimal 10. Jika ada gambar, tepat 1 harus primary.

file_name * content_type is_primary file action

Result: -

Upload New Images (Presigned)

Muncul setelah submit edit jika terdapat new_upload_urls dalam response. Upload via HTTP PUT ke presigned URL tanpa bearer token.

image_id object_key upload_url mapped_file replace_file status action

Confirm New Images

Konfirmasi hanya untuk gambar baru dengan status uploaded. Menggunakan endpoint POST /api/v1/vendors/products/{id}/images/confirm (endpoint yang sama dengan flow create product).
